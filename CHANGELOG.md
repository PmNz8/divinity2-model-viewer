# Changelog

## 0.2.1

- Translate Model diagnostics, Normalize for editing, and the normalization dialog into English.
- Add a Model Viewer screenshot to the repository README.
- No changes to model parsing, normalization rules or exported asset data.

## 0.2.0

- Version milestone for the visual-only CAT/ITEM, animation and d2model workflow.
- Exclude unused FreeGLUT DLLs and the OpenGL.GLUT module from Windows builds.
- Keep the Tk/WGL viewport and existing supported editing/export scope unchanged.
- Add a packaging regression test and Windows executable version metadata.
- Generate fresh build identity metadata instead of retaining an old source snapshot.

Collision preview/export and physics-bearing d2model v3/v4 remain unsupported.
