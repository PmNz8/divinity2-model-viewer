# Visual-only scope

Supported: visual v1/v2 packages, recognized CAT/ITEM embedded model edits,
textures, existing LODs, supported skeleton/animation preview and editing.
Static ITEM topology can change within existing component/material identities.
LOD editing is manual. Textures retain supported formats and dimensions.

Not supported: collision preview, import, editing, export or cooking; v3/v4
attachments; creating arbitrary CAT/ITEM from scratch; arbitrary skinned
topology or skeleton/rest-pose changes; unsupported asset layouts; automatic
map placement or installation. Enlarged visual models do not enlarge game
collision. No matching collider is generated by these tools.

Re-import a fresh visual v1/v2 package for this branch. Old Blender sessions
with extra authoring collections are not converted automatically. Exports use
new filenames and retain source identities; no silent attachment stripping.

The standard NIF object link slot is still read/preserved opaquely to maintain
the visual file's binary layout; its target is not interpreted as a collider.
